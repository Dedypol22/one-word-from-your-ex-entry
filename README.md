An entry for make.fun's "One Word From Your Ex" bounty. `main.py` (Python 3.13, standard library only) writes a single word — "Unreachable", the word an ex would use to describe you — to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). It stings twice over: emotionally unreachable, and literally never answers the phone. It is 11 characters, one word, and deterministic: every run produces the same bytes.

## Run it

```sh
python3 main.py
```

The word lands in `/output/entry.txt`.
